# Changelog

All notable changes to **GeoStar Selector for QGIS** are recorded here.

## v1.0.1 — 2026-08-31

- Synchronized the validated QGIS plugin package, source code and documentation.
- Improved cleanup and error logging for QGIS repository validation.
- Kept reliable crosshair map-tool activation.
- Supported magic-wand and polygon extraction workflows.
- Supported new, add, subtract and intersect selection modes.
- Supported RGB, 16-bit, floating-point and NoData raster data.
- Used visible-window reading for very large GeoTIFF imagery.
- Supported unknown-CRS PNG imagery and cross-CRS processing.
- Exported selections to Shapefile or GeoJSON.
- Standardized author attribution to **Zhang Y.H.**.

Release: https://github.com/zhangyhrs/GeoStar-Selector-QGIS/releases/tag/v1.0.1
